Aula 02

Aprendendo tipos de dados e variáveis: var, let, const

| Tipo        | Exemplo                            | Descrição                                |
| ----------- | ---------------------------------- | ---------------------------------------- |
| `number`    | `3.14`, `-10`, `0xFF`, `1e6`       | Números inteiros e de ponto flutuante    |
| `string`    | `"texto"`, `'a'`, `` `template` `` | Texto ou caracteres                      |
| `boolean`   | `true`, `false`                    | Lógico: verdadeiro ou falso              |
| `undefined` | `undefined`                        | Variável declarada, mas não inicializada |
| `null`      | `null`                             | Ausência intencional de valor            |
| `symbol`    | `Symbol("id")`                     | Identificadores únicos (avançado)        |
| `bigint`    | `12345678901234567890n`            | Inteiros muito grandes (>= 2⁵³)          |

Declarando variáveis em JavaScript

let: para variáveis reatribuídas.

let idade = 20;
idade = 21;

const: constantes que não mudam após definição

const PI = 3.14159
// PI = 3.14 -> ERRO!

var: era usado no ES6 (2015) mas agora não mais
var nome = "João";

Aula 03

Aprendendo a usar estruturas de controle: if, else, switch, for, while.
Aprendendo a usar operadores lógicos: +, -, *, /, %, **.

+  // soma
-  // subtração
*  // multiplicação
/  // divisão
%  // módulo (resto)
** // exponenciação

Para relacionais, temos:

==   // igual (com coerção de tipo) → ⚠️ evite
===  // igual estrito (sem coerção) → ✅ preferido
!=   // diferente (com coerção)
!==  // diferente estrito
>    // maior
>=   // maior ou igual
<    // menor
<=   // menor ou igual

Lógicos:
&&  // E (AND)
||  // OU (OR)
!   // NÃO (NOT)

Tarefa de aula
Crie um programa que:

Receba uma variável com a idade de uma pessoa.

Se a idade for menor que 18, escreva: "Menor de idade".

Se for entre 18 e 65, escreva: "Adulto".

Caso contrário, escreva: "Idoso".
