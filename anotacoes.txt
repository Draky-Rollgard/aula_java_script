var: era usado no ES6 (2015) mas agora não mais

Aula 06 

Aprendendo sobre JSON(JavaScript Object Notation)

JSON é um formato textual, padronizado, 
leve e independente de linguagem para troca de 
dados entre sistemas. 
Baseia-se na estrutura de objetos do JavaScript, 
mas pode ser usado por qualquer linguagem moderna.

Regras formais:

-Chaves devem ser strings entre aspas duplas (" ").
-Dados podem ser: número, string, 
 booleano, null, arrays ou outros objetos.


Aprendendo sobre API

Uma API (Application Programming Interface) é um 
conjunto de rotas (URLs) que permite que um sistema 
externo envie ou receba dados de um servidor.

Na Web, usamos APIs RESTful, que geralmente comunicam 
dados em formato JSON via HTTP (GET, POST, PUT, DELETE).

Aula 07

Aprendendo DOM 

O que é o DOM (Document Object Model)?
O DOM é uma representação em árvore de um 
documento HTML (ou XML), criada pelo navegador.
Cada tag HTML vira um nó (node) na árvore, e o 
JavaScript pode navegar, modificar, criar ou 
remover esses nós dinamicamente.

Exemplo de HTML:
html
Copiar código
<body>
  <h1>Olá Mundo</h1>
  <p id="mensagem">Texto original</p>
</body>

Como o navegador vê isso:
less
Copiar código
document
 └── html
     └── body
         ├── h1
         └── p (id="mensagem")

Acessar e manipular elementos do HTML com JavaScript
✅ Seletores – Como selecionar elementos:

| Método               | Exemplo                               | Descrição                                                            |
| -------------------- | ------------------------------------- | -------------------------------------------------------------------- |
| `getElementById()`   | `document.getElementById("mensagem")` | Seleciona **um elemento** com ID específico                          |
| `querySelector()`    | `document.querySelector("p")`         | Seleciona o **primeiro elemento** que bater com o seletor (CSS-like) |
| `querySelectorAll()` | `document.querySelectorAll("p")`      | Seleciona **todos os elementos** que batem com o seletor             |

Eventos no DOM

Um evento é qualquer ação que o usuário faz na página: 
clicar, digitar, passar o mouse, enviar um formulário, etc.

Principais:
| Evento      | Disparo                                         |
| ----------- | ----------------------------------------------- |
| `click`     | Quando um elemento é clicado                    |
| `mouseover` | Quando o mouse passa por cima                   |
| `mouseout`  | Quando o mouse sai de cima                      |
| `keydown`   | Quando uma tecla é pressionada                  |
| `submit`    | Quando um formulário é enviado                  |
| `change`    | Quando um `<input>` ou `<select>` muda de valor |
