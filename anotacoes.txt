Aula 02

Aprendendo tipos de dados e variáveis: var, let, const

| Tipo        | Exemplo                            | Descrição                                |
| ----------- | ---------------------------------- | ---------------------------------------- |
| `number`    | `3.14`, `-10`, `0xFF`, `1e6`       | Números inteiros e de ponto flutuante    |
| `string`    | `"texto"`, `'a'`, `` `template` `` | Texto ou caracteres                      |
| `boolean`   | `true`, `false`                    | Lógico: verdadeiro ou falso              |
| `undefined` | `undefined`                        | Variável declarada, mas não inicializada |
| `null`      | `null`                             | Ausência intencional de valor            |
| `symbol`    | `Symbol("id")`                     | Identificadores únicos (avançado)        |
| `bigint`    | `12345678901234567890n`            | Inteiros muito grandes (>= 2⁵³)          |

Declarando variáveis em JavaScript

let: para variáveis reatribuídas.

let idade = 20;
idade = 21;

const: constantes que não mudam após definição

const PI = 3.14159
// PI = 3.14 -> ERRO!

var: era usado no ES6 (2015) mas agora não mais
var nome = "João";

Aprendendo a usar operadores lógicos: +, -, *, /, %, **.

+  // soma
-  // subtração
*  // multiplicação
/  // divisão
%  // módulo (resto)
** // exponenciação

Para relacionais, temos:

==   // igual (com coerção de tipo) → ⚠️ evite
===  // igual estrito (sem coerção) → ✅ preferido
!=   // diferente (com coerção)
!==  // diferente estrito
>    // maior
>=   // maior ou igual
<    // menor
<=   // menor ou igual

Lógicos:
&&  // E (AND)
||  // OU (OR)
!   // NÃO (NOT)

Aula 06 

Aprendendo sobre JSON(JavaScript Object Notation)

JSON é um formato textual, padronizado, 
leve e independente de linguagem para troca de 
dados entre sistemas. 
Baseia-se na estrutura de objetos do JavaScript, 
mas pode ser usado por qualquer linguagem moderna.

Regras formais:

-Chaves devem ser strings entre aspas duplas (" ").
-Dados podem ser: número, string, 
 booleano, null, arrays ou outros objetos.


Aprendendo sobre API

Uma API (Application Programming Interface) é um 
conjunto de rotas (URLs) que permite que um sistema 
externo envie ou receba dados de um servidor.

Na Web, usamos APIs RESTful, que geralmente comunicam 
dados em formato JSON via HTTP (GET, POST, PUT, DELETE).
